# FB Video Downloader - Developed by NDL Developer

![NDL Developer Logo](./public/ndl-logo.jpg)

Website tải video Facebook tốc độ cao, hỗ trợ chất lượng Full HD, HD, SD được xây dựng trên nền tảng **Next.js 14+ (App Router, TypeScript, Tailwind CSS)** bởi **NDL Developer**.

## 🌟 Tính Năng Nổi Bật
- **Hỗ trợ đa định dạng link FB**: Facebook Reels, Facebook Watch, Post chứa video, Livestream đã xong.
- **Xem trước Video (Preview Player)**: Xem phát trực tiếp video trước khi tải về.
- **Tải file MP4 trực tiếp**: Proxy stream bypass CORS & tự động lưu file `.mp4`.
- **Giao diện hiện đại**: Dark mode, Glassmorphism, Responsive hoàn hảo trên Mobile & PC.
- **Thương hiệu & Logo**: Tích hợp hình ảnh và thông tin nhận diện thương hiệu NDL Developer.

## 🛠 Hướng Dẫn Cài Đặt & Chạy

```bash
# Khởi chạy server phát triển local
npm run dev
```

Mở trình duyệt tại: `http://localhost:3000`
